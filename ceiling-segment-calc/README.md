# Ceiling Segment Calculator

WordPress-плагін для відновлення криволінійної сторони натяжної стелі за замірами «радіус + сегмент». Працює повністю у браузері: без бекенду, без зовнішніх бібліотек і без мережевих запитів.

## Що робить

1. Імпортує контур кімнати з файлу **`.glc`** (Arkulator): кути `POINTS`/`AnglePoint` і сторони `otrlist_`/`NPLine`, включно з дугами.
2. Дає вибрати **согнутую сторону** двома кутами: початковий **S** і кінцевий **E**.
3. Приймає таблицю замірів: для кожної точки — **радіус d від кута O** і **довжина сегмента s** від попередньої точки. Останній рядок — сам кут **E**.
4. Відновлює криву методом найменших квадратів, показує її на SVG-прев’ю, рахує площу, периметр і відхилення.
5. Дозволяє **перетягнути точки** мишею (ручне коригування), **віддзеркалити** результат (Y), зберегти проміжний стан у **JSON** (плюс автозбереження в `localStorage`).
6. Експортує готовий **`.glc`** (windows-1251, CRLF), **`.dxf`** (R12 POLYLINE з bulge) і **`.svg`**.

## Встановлення

1. Завантажте папку `ceiling-segment-calc` у `wp-content/plugins/` (або zip через «Плагіни → Додати новий → Завантажити плагін»).
2. Активуйте плагін **Ceiling Segment Calculator**.
3. Додайте на сторінку шорткод:

```
[ceiling_segment]
```

### Атрибути шорткода

| Атрибут | За замовчуванням | Опис |
|---|---|---|
| `unit` | `mm` | Одиниці таблиці замірів: `mm`, `cm`, `m`. Геометрія `.glc` завжди в мм. |
| `rows` | `6` | Початкова кількість рядків (1–100). |
| `sigma` | `3` | Похибка заміру σ, мм. Впливає на ваги МНК і пороги попереджень. |
| `title` | «Калькулятор сегментів кривої стелі» | Заголовок блоку. |

Приклад: `[ceiling_segment unit="cm" rows="10" sigma="2"]`

## Порядок роботи

1. **Попередній контур.** У Arkulator намалюйте приблизний контур кімнати (прямі сторони + орієнтовна крива) і збережіть як `.glc`.
2. **Імпорт.** Натисніть «Завантажити .glc». Плагін покаже кількість кутів і сегментів.
3. **Сторона.** Виберіть початковий кут **S** і кінцевий **E** согнутой сторони. Порядок — уздовж контуру; якщо сторона перетинає початок списку, це теж підтримується.
4. **Кут O.** Вкажіть, звідки міряли радіуси:
   - «кут контуру» — виберіть кут зі списку;
   - «ручна точка X,Y» — введіть координати в обраних одиницях. Кут O може **не входити** в контур (декоративний виріз).
5. **Таблиця.** Для кожної точки введіть:
   - `d` — відстань від O до точки;
   - `s` — відстань від попередньої точки (для першого рядка — від S).
   Останній рядок таблиці — це кут **E**; його `d` і `s` використовуються як контроль.
6. **Перевірка.** Дивіться бейджі `✓/⚠/✗` у таблиці та «Максимальні відхилення». Якщо точка «пливе», її можна перетягнути на прев’ю. Кнопка «Скинути правки» повертає розрахункові положення.
7. **Збереження.** Стан автоматично зберігається в браузері. Кнопки «Зберегти стан» / «Завантажити стан» зберігають повний JSON (контур + заміри + правки) для передачі колезі.
8. **Експорт.** «Завантажити GLC» — файл для Arkulator; DXF/SVG — для перевірки та друку.

## Методика замірів

- Точки ставляться **по порядку від S до E**.
- `s` — це **хорда**: пряма відстань між сусідніми позначками (рулетка натягнута прямо). Якщо міряли по дузі, для типових радіусів різниця між хордою й дугою — частки міліметра.
- Остання точка — кут **E**. Якщо зручніше, останній рядок можна заповнити вимірами саме до кута E.
- Кут **O** може бути кутом кімнати або окремою точкою (наприклад, кут декоративного вирізу).

## Обмеження v1

- Одна согнутая сторона за один розрахунок (один ланцюг точок).
- З `.glc` береться **перша кімната**; внутрішні вирізи (`VIREZS`) не обробляються.
- Координати кута O через тріангуляцію від двох кутів не реалізовано — вводьте X,Y вручну.
- Імпорт не перевірявся відкриттям у реальній CAD Arkulator (у середовищі розробки CAD недоступна). Формат і експорт перевірені тестами на реальних `.glc` з репозиторію.
- Плагін формує нові `UID1`/`ZoneGUI1`; підпис чи інші метадані оригіналу не зберігаються.

## Приватність

Усі обчислення виконуються локально в браузері. Файли `.glc`/JSON нікуди не надсилаються.

## Розробка

```
ceiling-segment-calc/
  ceiling-segment-calc.php   # шорткод, реєстрація ассетів
  assets/csc-core.js         # парсер .glc, решатель, збирання контуру, експорт
  assets/csc-ui.js           # інтерфейс, SVG-прев’ю, зум/панорама, drag
  assets/csc.css             # стилі (префікс csc-)
  tests/run-tests.js         # 22 тести ядра (Node)
  tests/php-shortcode-test.php
  tests/stand.html           # стенд для ручної/Playwright-перевірки
  tests/server.js            # локальний статичний сервер
```

Запуск тестів:

```
node tests/run-tests.js
php tests/php-shortcode-test.php
node tests/server.js   # http://127.0.0.1:8775/
```

Детальні рішення, припущення та відомі ризики — у `DEV_NOTES.md`.
