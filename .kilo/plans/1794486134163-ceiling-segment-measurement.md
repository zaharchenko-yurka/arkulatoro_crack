# План: замер кривой стороны потолка по сегментам (отдельный WP-плагин)

## Контекст
Репозиторий `D:\Repos\arkulatoro_crack`. Уже реализован плагин `ceiling-contour-calc` (трилатерация по двум углам, упрощение контура, экспорт GLC/DXF/SVG, превью на SVG, localStorage, шорткод, 242 юнит-теста, Playwright-UI). Есть реверс-спецификация `.glc` в `ai-docs/` и эталон конвертера DXF→GLC в `dxf-glc-converter/` (его `glcBuilder.js`, `contourBuilder.js`, `svgRenderer.js` — образцы для портирования).

Пользователь замеряет кривую сторону (скриншоты 3, 4, 5): один угол-опора O, радиусы до точек стыков сегментов и длины сегментов. O может не входить в контур (скриншоты 3, 4 — декоративный вырез). Требуется автоматизация: импорт контура из Аркулятора, восстановление кривой стороны, превью, корректировка, сохранение промежуточных результатов, зеркало, экспорт `.glc`.

## Цель
Новый WordPress-плагин без бэкенда, вставляется шорткодом на страницу. Весь расчёт — в браузере (чистый JS). На входе: `.glc` комнаты от Аркулятора + таблица замеров кривой стороны. На выходе: восстановленный контур на SVG-превью, скорректированный пользователем, и готовый файл `.glc` (и DXF, SVG) для Аркулятора.

## Принятые решения
1. **Отдельный плагин** (не расширение `ceiling-contour-calc`): свои префиксы классов/стилей, свой шорткод, своя папка; логика ядра/экспорта портируется из `ceiling-contour-calc` и `dxf-glc-converter`.
2. **Геометрия комнаты — импорт `.glc`**: парсер `POINTS`/`AnglePoint` + `otrlist_`/`NPLine` (дуги — через `ArcPoint`/`ArcHei`). Ручная таблица углов без `.glc` — v2.
3. **Способ замеров**: один угол-опора O + радиусы до точек стыков + длины сегментов. Двухточечная трилатерация (скриншоты 3, 4 по сути тот же способ) не нужна.
4. **Опорные концы согнутой стороны — фиксированы** (углы из импортированного контура). Сегменты — мягкие ограничения с глобальной уточняющей оптимизацией («разрешить сдвигать»); концы цепи — жёсткие.
5. **Zеркалирование** результата (отражение Y) — эскиз «вид снизу» → нужный «вид сверху».
6. **Сохранение промежуточных результатов**: автосохранение в `localStorage` + экспорт/импорт снимка состояния JSON.
7. **Вывод**: `.glc` (весь контур комнаты с восстановленной кривой стороной), DXF R12, SVG-превью/экспорт.

## Задачи (в порядке выполнения)

1. **Каркас плагина**: папка плагина, заголовок PHP, шорткод, регистрация/подключение ассетов только при наличии шорткода, префиксы функций/классов, `<noscript>`, `if (!defined('ABSPATH')) exit;`.
2. **Парсер `.glc` (импорт)**: углы контура (POINTS/AnglePoint со значениями), стороны (otrlist_/NPLine: PoBeg/PoEnd, дуга — ArcPoint/ArcHei, признак кривой стороны по наличию ArcHei). Тесты на образцах из репозитория (`033273.glc`, `033273_1.glc`, `033271.glc`).
3. **Модуль решателя цепи** (чистый JS, тестируется в Node):
   - посев: последовательное пересечение окружности «конец предыдущего сегмента — длина сегмента» с окружностью «O — радиус», выбор решения по поддерживаемой стороне цепи (детерминированно);
   - уточнение: нелинейные наименьшие квадраты (Гаусс–Ньютон) над промежуточными вершинами с фиксированными концами, минимизация остатков по радиусам и длинам сегментов;
   - отчёт остатков по каждой точке и сегменту, предупреждения при превышении порога (связано с похибкой заміру σ);
   - фиксированные концы цепи не меняются.
4. **UI**:
   - загрузка `.glc`, выбор согнутой стороны (из импортированных) и угла O (угол контура или ручная точка X,Y, мм);
   - таблица замеров: точка, радиус от O, длина сегмента, флаги, статус/остаток;
   - SVG-превью: полигон комнаты, выделение согнутой стороны, радиусные линии от O, точки стыков с номерами, остатки, зум/панорама, кнопка «Підігнати до екрана»;
   - переключатель зеркала Y, мгновенная перерисовка.
5. **Ручная правка и промежуточные результаты**: перетаскивание/редактирование точек на превью с пересчётом, автосохранение в `localStorage`, кнопки «Зберегти стан JSON» / «Завантажити стан JSON».
6. **Экспортеры**: `.glc` (windows-1251, CRLF, по образцу `ceiling-contour-calc/buildGlc`: ROOMBEGIN…ROOMEND, GVals, ZONESLIST, otrlist_ с дугами), DXF R12 (POLYLINE с bulge), SVG.
7. **Тесты**: узловые тесты решателя на синтетических цепях с известной дугой и шумом σ = 0/2/3 мм (площадь/периметр ≤ 0.5%, остатки ≤ порог); тесты парсера `.glc` на образцах репо; Playwright-сценарии (загрузка, сбор, зеркало, скачивание файлов, отсутствие горизонтального скролла); `php -l` плагина.
8. **Упаковка**: zip-архив для установки через «Плагіни → Додати новий → Завантажити плагін».

## Риски
- **Парсер `.glc` не проверялся в реальной CAD Аркулятор** (CAD недоступна в окружении). Смягчение: тесты на реальных `.glc` из репозитория + собственный валидатор-парсер в тестах.
- **Несходимость цепи** при сильном шуме или узком изгибе — остатки + предупреждения + ручная правка точек.
- **Двусмысленность посева** (два пересечения окружностей) — детерминированный выбор стороны цепи + ручная корректировка в превью.

## Валидация (приёмка)
- Синтетические цепи с известной дугой + шум: ошибка площади/периметра ≤ 0.5%, остатки по радиусам и сегментах ≤ допуск.
- Импорт `.glc` образцов репозитория: баланс блоков, координаты углов, дуги.
- Playwright: загрузка файла, построение контура, зеркало, скачивание `.glc`/DXF/SVG, нет горизонтального скролла на десктопе и мобильном.
- PHP: `php -l` без ошибок; шорткод выводит плагин на тестовой странице (если WP доступен; иначе фиксируется как непроверенное).
